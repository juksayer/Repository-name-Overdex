ODX-FI Design Principles
Purpose

The ODX-FI is a field instrument.

It is not a game console.

Its purpose is to reduce cognitive load so the trainer can focus on the battle.

1. Function Determines Appearance

Every visible feature must improve observation, usability, or serviceability.

Nothing exists solely for visual appeal.

2. The Instrument Never Competes With the Observation

The trainer's attention belongs to the battle.

3. Reduce Cognitive Load

The instrument should never ask the trainer to remember something it can remember itself.

Memory is a system responsibility.

Decision-making remains the trainer's responsibility.

4. Minimal Effort, Maximum Communication

Use the smallest effective action to communicate the greatest amount of information.

Every sound, light, animation, and interaction should be intentional.

5. Complexity Belongs Inside

The system may manage complex observations, probabilities, timelines, and confidence internally.

Present only the information required to make the next decision.

6. Every Output Channel Has One Purpose

CRT — Observation

Service LCD — Context

LEDs — State

Speaker — Acknowledgement

Droidball — Intent

Output channels complement one another.

They never compete.

7. Hardware Earns Trust

The enclosure should communicate durability, serviceability, and purpose.

Visible construction, restrained styling, and deterministic controls inspire confidence.

8. Battle and Discovery Are Different Modes

Battle prioritizes speed and clarity.

The Pokédex rewards curiosity and exploration.

Neither mode should compromise the other.

9. Droidball Is the Senior Curator

Droidball preserves knowledge.

He appears only when needed.

He identifies the relevant article, presents the knowledge, offers DetailView, and quietly departs.

The information—not Droidball—is the focus.

10. Build by Answering Questions

Overdex grows by solving real observation problems.

Each answer should naturally reveal the next question.

Architecture should emerge from genuine needs rather than speculative features.
