# ODX-FI Hardware Specification

## Displays

### Primary Display

- Portrait-oriented CRT
- Primary operator workspace
- Displays navigation, observation, battle data, Pokédex, and system interfaces.
- Optimized for text density rather than video playback.

### Instrument Display

- Permanent secondary LCD.
- Always visible.
- Provides contextual information related to the current CRT selection.
- Never replaces the primary workspace.

## Controls

Navigation Column

- Up
- Down
- Left
- Right

Action Column

- A
- B
- Select
- Start

All interaction occurs through dedicated hardware controls.

The CRT is not a touchscreen.

## Status Indicators

Three LEDs

- Power
- Observation
- Link / Activity

LED meanings may change based on operating mode.

# Binder UI

CRT

- Displays binder pages.
- Displays page navigation.
- Displays selection cursor.

Instrument LCD

Displays details for the currently selected Pokémon.

Updates automatically as selection changes.

No user interaction occurs directly on the LCD.
