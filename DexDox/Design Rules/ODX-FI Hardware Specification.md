# ODX-FI Hardware Specification

## Displays

### Primary Display

- Portrait-oriented CRT
- Primary operator workspace
- Displays navigation, observation, battle data, Pokédex, and system interfaces.
- Optimized for text density rather than video playback.

### Instrument Display

- Permanent secondary LCD.
- Always visible.
- Provides contextual information related to the current CRT selection.
- Never replaces the primary workspace.

## Controls

Navigation Column

- Up
- Down
- Left
- Right

Action Column

- A
- B
- Select
- Start

All interaction occurs through dedicated hardware controls.

The CRT is not a touchscreen.

## Status Indicators

Three LEDs

- Power
- Observation
- Link / Activity

LED meanings may change based on operating mode.

# Binder UI

CRT

- Displays binder pages.
- Displays page navigation.
- Displays selection cursor.

Instrument LCD

Displays details for the currently selected Pokémon.

Updates automatically as selection changes.

No user interaction occurs directly on the LCD.

ODX-FI Body v1.0
Overall Philosophy

ODX-FI is not a robot.

It is not a desktop computer.

It is a field instrument that happens to dock Droidball.

Think:

laboratory equipment
avionics test station
surveying instrument
military field electronics

It should look like something built to work for decades.

Overall Shape

A broad, stable base.

Slight wedge profile.

Heavy enough that docking Droidball feels intentional.

Nothing delicate.

Materials

Matte textured polymer shell.

Rubberized feet.

Visible screws.

Small service panels.

Tiny molded labels.

It should feel repairable instead of disposable.

CRT

The CRT remains the visual centerpiece.

Not huge.

Not tiny.

Large enough to feel like a service monitor.

Slightly recessed.

Protective bezel.

Very subtle scanlines.

Service LCD

Mounted beneath the CRT.

Wide.

Shallow.

Industrial monochrome appearance.

This becomes the UI that Droidball later recreates in battle.

Droidball Dock

Center front.

Slightly recessed.

Magnetic guidance.

Electrical contacts hidden.

He should appear to belong there rather than sit on top.
